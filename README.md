# AI-ON: AI-Powered Voice Assistant for Task Automation

AI-ON is an intelligent voice-based virtual assistant developed using Python, Flask, JavaScript, Selenium, and MongoDB.

## Features
- Voice command recognition using Web Speech API
- Text-to-Speech response system
- ERP attendance automation using Selenium
- Google and YouTube search automation
- Automated leave email generation with PDF attachment
- JWT-based user authentication
- Secure password hashing using Bcrypt
- MongoDB user data and memory storage
- Local application / presentation opening via voice command

## Technologies Used
- Python
- Flask
- JavaScript
- HTML / CSS / Tailwind CSS
- Selenium WebDriver
- MongoDB
- JWT
- Bcrypt
- Yagmail
- ReportLab
- Web Speech API
